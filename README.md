День 2 — Архитектура промптов и управление качеством ответа

🎯 Цель дня
Научиться управлять поведением модели через system prompt, шаблоны пользовательских инструкций и явные ограничения формата.

📋 Задачи
1. 🧠 Вынести system prompt в отдельную переменную или файл
2. 📝 Сделать prompt template для пользовательского текста
3. 🔬 Сравнить минимум 3 варианта формулировки промпта на одних и тех же входах
4. 📏 Добавить ограничения:
   - максимальная длина summary
   - ровно 3 key points
   - короткий итоговый ответ
5. 🧪 Прогнать пайплайн снова на 3–5 тестовых текстах
6. 📓 Кратко зафиксировать, какой prompt оказался лучшим и почему

Что важно понять
Модель отвечает по-разному в зависимости от:
- system prompt
- формулировки инструкции
- требуемого формата ответа

🎉 Критерии успеха
- ✅ Промпты отделены от кода пайплайна
- ✅ Есть system prompt и user template
- ✅ Проведено сравнение минимум 3 prompt-вариантов
- ✅ Выбран и зафиксирован лучший вариант
- ✅ Ответы стали заметно стабильнее и аккуратнее
