День 3 — Structured output и валидация JSON

🎯 Цель дня
Научить модель возвращать структурированный ответ и валидировать его схемой, чтобы LLM стала частью инженерного пайплайна.

📋 Задачи
1. 📦 Изменить формат ответа модели на JSON
2. 📐 Задать структуру ответа с полями:
   - summary
   - category
   - sentiment
   - key_points
   - final_answer
3. 🧱 Создать Pydantic-схему или аналогичную валидацию
4. ⚠️ Обработать кейс, когда модель вернула:
   - невалидный JSON
   - пропущенные поля
   - неправильный тип данных
5. 🧪 Проверить пайплайн на минимум 5 примерах
6. 📝 Добавить понятное сообщение об ошибке, если JSON сломан

🎉 Критерии успеха
- ✅ Модель возвращает JSON-ответ
- ✅ Ответ проходит валидацию схемой
- ✅ При плохом JSON программа не падает бесконтрольно
- ✅ Минимум 5 примеров успешно обрабатываются
- ✅ Поля structured output реально используются, а не просто печатаются
