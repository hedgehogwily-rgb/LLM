День 1 — Базовый LLM pipeline для обработки текста

🎯 Цель дня
Поднять первый рабочий пайплайн, который принимает текст, обращается к модели и возвращает полезный результат, а не просто сырой ответ LLM.

📋 Задачи
1. 🔑 Подключить LLM API через переменные окружения (OPENAI_API_KEY или совместимый ключ)
2. 🧱 Создать базовую структуру проекта:
   - main.py
   - llm_client.py
   - prompts.py
3. 🤖 Реализовать клиент для вызова модели
4. 📥 Сделать функцию, которая принимает текст и возвращает:
   - short summary
   - 3 ключевые мысли
   - short helpful response
5. 🧪 Подготовить минимум 3 тестовых текста и прогнать пайплайн на них
6. 📝 Вывести результат в читаемом виде в консоль или сохранить в JSON-файл

Подсказка по структуре
- В llm_client.py держите только вызов API
- В prompts.py храните шаблон промпта
- В main.py собирайте всё вместе

🎉 Критерии успеха
- ✅ Проект запускается без ручного редактирования кода под каждый текст
- ✅ Есть отдельный модуль вызова LLM
- ✅ Для каждого из 3 тестовых текстов система возвращает summary, key points и ответ
- ✅ Результат можно посмотреть в структурированном виде
