День 5 — Multi-step LLM chain

🎯 Цель дня
Собрать полноценный многошаговый workflow, где результат одного шага используется на следующем.

📋 Задачи
1. ⛓️ Построить цепочку обработки из нескольких шагов:
   1. extract meaning
   2. classify request
   3. build structured fields
   4. generate final answer
   5. self-check result
2. 🧠 Сделать так, чтобы шаг final_answer использовал результаты предыдущих шагов
3. 🔍 Добавить self-check шаг, который проверяет:
   - не противоречит ли ответ входному тексту
   - не потеряны ли важные детали
4. 🧪 Протестировать пайплайн на 5–10 примерах
5. 📝 Показать в логах или выводе, как проходит текст через все шаги

🎉 Критерии успеха
- ✅ Пайплайн состоит минимум из 4 последовательных этапов
- ✅ Каждый шаг использует результат предыдущего
- ✅ Есть отдельный шаг проверки результата
- ✅ По логам или выводу видно, как система принимает решение
- ✅ На 5–10 примерах система проходит весь цикл без ручного вмешательства
