День 4 — Классификация и routing логика

🎯 Цель дня
Научить систему определять тип входного текста и менять способ ответа в зависимости от категории.

📋 Задачи
1. 🏷️ Ввести категории запросов, например:
   - support
   - feedback
   - complaint
   - sales
   - general_question
2. 🤖 Научить модель определять категорию и intent
3. 🔀 Реализовать routing logic:
   - для разных категорий разные инструкции на генерацию ответа
4. 🧪 Подготовить минимум 8–10 тестовых текстов разных типов
5. 📊 Проверить, что категория реально влияет на итоговый ответ

Пример
- complaint → более аккуратный и эмпатичный ответ
- sales → короткий продающий ответ
- support → структурированный технический ответ

🎉 Критерии успеха
- ✅ Есть список категорий
- ✅ Модель определяет категорию не менее чем на 8 тестовых примерах
- ✅ Итоговый ответ зависит от категории
- ✅ Routing реализован явно в коде, а не только внутри одного огромного промпта
