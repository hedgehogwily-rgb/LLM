# Заметки по промптам

## День 2 — сравнение формулировок (архив)

На этапе day 2 сравнивали 3 варианта на одних и тех же входах.
Артефакт сравнения сохранён в `comparison.json`.

| Вариант | Идея | Score |
|---|---|---|
| `v1_basic` | Мягкая инструкция без жёстких лимитов | 12/15 |
| `v2_strict` | Жёсткие лимиты длины | 15/15 |
| `v3_structured` | JSON-schema + лимиты + конкретные points | 15/15 |

**Победитель day 2:** `v3_structured` — стабильнее формат и конкретнее key points.

Ограничения, которые закрепили дальше в схеме:
- `summary` ≤ 25 слов
- ровно 3 `key_points`
- короткий `final_answer` (сейчас ≤ 4 предложения; точки в нумерации `1.`/`2.` не считаются концом фразы)

## День 4 — текущий production-пайплайн

Сейчас в коде **не** используются `v1/v2/v3` как единый мега-промпт.
Рабочий поток:

1. `classify` → `category` + `intent`
2. `router.route(category)` → явный выбор style-промпта в Python
3. `generate_routed_answer` → JSON со схемой  
   `summary`, `category`, `sentiment`, `key_points`, `final_answer`

Style-промпты лежат в `RESPONSE_PROMPTS` (`prompts.py`):
- `complaint` — эмпатия
- `sales` — короткий продающий ответ
- `support` — технические шаги
- `feedback` — благодарность
- `general_question` — нейтральный ответ

Итог: идеи day 2 (жёсткий формат + лимиты) сохранены в Pydantic-схеме,
а day 4 добавляет classify → route в коде, а не «if category» внутри одного промпта.
