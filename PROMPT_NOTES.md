# День 2 — сравнение промптов

Сравнивали 3 варианта на 5 одинаковых текстах (`texts/text1.txt` … `text5.txt`).

## Варианты

| Вариант | Идея | Score (ограничения) |
|---|---|---|
| `v1_basic` | Мягкая инструкция без жёстких лимитов | **12/15** |
| `v2_strict` | Жёсткие лимиты длины и «ровно 3 points» | **15/15** |
| `v3_structured` | Schema JSON + лимиты + требование конкретных non-overlapping points | **15/15** |

Проверяемые ограничения:
- summary ≤ 25 слов
- ровно 3 `key_points`
- `helpful_response` ≤ 2 предложения

## Наблюдения

- `v1_basic` часто давал **4** key points — формат нестабильный.
- `v2_strict` стабильно держал лимиты, но иногда points слишком общие (`"Снижают стресс."`).
- `v3_structured` тоже 15/15, при этом формулировки обычно конкретнее и меньше пересекаются.

## Победитель

**Лучший: `v3_structured`**

Почему:
1. Соблюдает ограничения так же стабильно, как `v2_strict`.
2. Явная JSON-schema и запрет лишних полей делают ответ предсказуемее.
3. Требование конкретных non-overlapping points повышает полезность результата, а не только формальную длину.

Файлы:
- сравнение: `comparison.json`
- финальный прогон: `results.json`
- код промптов: `prompts.py` (`DEFAULT_VARIANT = "v3_structured"`)
